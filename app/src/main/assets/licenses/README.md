# License texts

The full texts the app's bundled components are under; which component
is under which is listed in the README's "Third-party libraries" and, for
the viewer's grammars, in `assets/textmate/NOTICE.md`.

- `LGPL-2.1.txt`: Sora Editor (editor, language-textmate)
- `EPL-2.0.txt`: Eclipse tm4e (inside language-textmate), Eclipse JDT annotations
- `MIT.txt`: joni, jcodings, most grammars, and others
- `Apache-2.0.txt`: Gson, snakeyaml-engine, the Dockerfile grammar, and others
- `TextMate-Bundle.txt`: the TextMate bundles some grammars come from
