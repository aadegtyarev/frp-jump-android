# License texts

The full texts the app's components are under, shown in Settings ›
Components and licenses (which component is under which comes from
`res/raw/aboutlibraries.json`, made at build time; see the README's
"Settings" and "Third-party libraries").

- `Apache-2.0.txt`: AndroidX, Kotlin, OkHttp, sshj, Netty, HiveMQ, Gson, frpc, the Dockerfile grammar, and others
- `MIT.txt`: joni, jcodings, slf4j, most grammars
- `MIT-0.txt`: Reactive Streams
- `LGPL-2.1.txt`: Sora Editor (editor, language-textmate)
- `EPL-2.0.txt`: Eclipse tm4e (inside language-textmate), Eclipse JDT annotations
- `BouncyCastle.txt`: Bouncy Castle (MIT-style)
- `BSD-3-Clause-libyuv.txt`: libyuv, inside CameraX's camera-core
- `BSD-3-Clause-Go.txt`: the Go standard library and golang.org/x packages inside frpc
- `TextMate-Bundle.txt`: the TextMate bundles some grammars come from
