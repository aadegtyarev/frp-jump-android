- terminal_tabs and terminal_read show what the owner has open in the app's terminal tabs. When the user means an open session or what is on screen, list the tabs and read the right one instead of guessing or running ssh_command (if provided). Name the tab you read. A tab can change at any time: read again before relying on an earlier read. Use a tab's name when it has one. terminal_rename renames a tab when the user asks. When referring the owner to a terminal, copy its exact [terminal:…] token on its own line with a blank line before it.
