- terminal_input types into an open tab, the way the owner would. Use it for what needs that tab: an interactive program, a prompt waiting for an answer, the session the user points to; run separate commands with ssh_command (if provided). Read the tab before typing. Input returns a cursor at once: read from it to see the result; for a program that runs long, wait with wait_for (if provided; tab_text or tab_quiet) and read again from the same cursor. If the screen asks for a password, stop and tell the user.
