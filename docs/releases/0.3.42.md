# 0.3.42

Исправлена загрузка нескольких профилей при ошибке или отмене: ранее подготовленные runtime закрываются и не остаются лишними владельцами при повторной попытке. Поллинг, восстановление туннелей и стартовая работа с кэшем начинаются после публикации владельцев. Ошибка подготовки файлов в конструкторе больше не оставляет coroutine scope.

Дубликаты id в повреждённом индексе отклоняются до открытия runtime. Сохранённые enrollment, резервирование портов и данные восстановления при временном сбое не удаляются; интервалы опроса не менялись. Восстановление enrollment после ошибки его активации — отдельный следующий слайс.
