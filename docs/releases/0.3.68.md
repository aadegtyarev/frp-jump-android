## Несколько картинок за раз

- В выборе фото можно отметить до 10 картинок. Это работает из меню ⋮, по долгому нажатию на «Вставить» и через кнопку в редакторе текста. Если в буфере телефона несколько картинок, вставятся все.
- Картинки отправляются по очереди через одно соединение. Полоса загрузки показывает «Изображение N из M». «Отмена» останавливает всю пачку: ничего не вставляется, уже отправленные файлы этой пачки удаляются.
- Пути вставляются одной строкой через пробел, в порядке выбора. Claude Code показывает их как отдельные вложения.
- Если часть картинок не отправилась, удачные всё равно вставляются, а приложение коротко сообщает, сколько не отправлено и почему.
- Буфер обмена читается только после того, как вы подтвердите вставку.

## Подсказка на клавише «Вставить»

- В углу клавиши «Вставить» появился маленький значок картинки: он показывает, что долгое нажатие вставляет изображение. Когда это сейчас недоступно, значок приглушён.
