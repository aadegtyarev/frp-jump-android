## Исправление

- Если не удалось сохранить доверие к ключу хоста (или забыть старый ключ), приложение больше не закрывается вместе с туннелями. Терминал завершается с понятной ошибкой, Files и «Использовать вход по ключу» показывают её с кнопкой «Повторить». Ключ при этом не становится доверенным, а старый остаётся прежним.
