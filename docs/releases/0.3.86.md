## Чат помощника: вызовы инструментов понятнее и тише

- **Каждый вызов подписан тем, что он запрашивал.** Сведения о профилях — запрос в кавычках, имя профиля, «с 14-й записи» для следующей страницы или «все». Команда SSH — устройство и команда. Просьба включить инструмент — его название. Служебные имена вроде `profile_information` больше не показываются.
- **Пока помощник работает,** каждый вызов — своя строка с подписью. Одинаковые вызовы с одинаковыми параметрами склеиваются в «×2».
- **Без двойного заголовка.** Если в ходе вызывался один инструмент, нажатие на «Сведения о профилях ×2» сразу показывает вызовы. Раньше открывалась вторая такая же строка, которую нужно было нажать ещё раз.
- **Полученные сведения о профилях — мелким серым текстом,** как остальные результаты инструментов. Они не спорят с ответом. ID профиля показан только у записи самого профиля, а не под каждым устройством.
- **Поле ввода во время работы пустое.** Отправленный текст уже стоит в ленте. Если ответ не пришёл или вы нажали «Стоп», текст возвращается в поле.
