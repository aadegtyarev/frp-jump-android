## Помощник

- Помощник может отправлять HTTP POST с JSON или текстом через открытый сохранённый веб-туннель. Включите «HTTP POST» в инструментах помощника.
- В карточке подтверждения видны адрес, путь с параметрами, тип содержимого и всё тело запроса. Разрешение для сессии или подключения распространяется только на POST.
- При потере ответа помощник сообщает, что результат неизвестен. Запрос автоматически не повторяется.
