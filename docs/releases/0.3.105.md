## Удобнее работать с туннелями

- Карточки туннелей стали компактнее: адрес, состояние и действия легче просматривать вместе. У активных SSH-туннелей значок папки выделен цветом.
- В выборе устройств видны подписи устройств; при нескольких профилях устройства сгруппированы по профилям. Список можно искать и прокручивать, а выбор — быстро сбросить.
- Для устройства без туннелей показано понятное действие добавления. Элементы заголовка теперь оформлены единообразно.
- При вводе поиска поле занимает всю ширину заголовка. После выхода из поиска фильтры возвращаются, а введённый запрос остаётся применённым.
