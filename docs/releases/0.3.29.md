- Терминал: переключатель «Клавиши / Текст». В режиме «Текст» вместо дополнительных рядов клавиш появляется видимое многострочное поле. Можно пользоваться подсказками, исправлениями и голосовым вводом клавиатуры, не отправляя набираемое в SSH.
- Редактор разворачивается на весь экран. При сворачивании и возврате к клавишам текст и выделение сохраняются. У каждой SSH-вкладки свой черновик, только в памяти процесса; после закрытия или замены сессии он удаляется.
- «Вставить» передаёт черновик в исходную вкладку через обычные проверки вставки, без дополнительного Enter. Многострочный текст без bracketed paste требует подтверждения, как и раньше. Отмена или ошибка оставляют черновик; принятая локально вставка очищает отправленную версию, но не более новые правки.
- Обычные терминальные кнопки работают с терминалом и не отправляют черновик. По умолчанию остаётся режим «Клавиши»; сохранённая настройка прямого ввода не меняется.
- Пустая строка «+ Добавить команду» больше не занимает место. Сохранённые команды остаются; редактор доступен через «⋮ → Команды».

Terminal: an explicit Keys/Text switch replaces the additional key rows with a visible multiline composer. Expand/collapse shares the draft and selection. Drafts are session-specific and memory-only. Insert uses the existing paste checks, remains bound to the captured session and adds no Enter. Cancellation and failed insertion retain text; accepted local insertion clears only the submitted revision. The default Keys surface and stored direct-input preference are unchanged.
