## Один экран «Туннели» для всех устройств

- «Устройства» открывают список туннелей сразу с нужным устройством и профилем. В общем списке можно выбрать несколько устройств, искать и показывать только активные туннели.
- Несколько активных туннелей можно отключить одним действием и отменить отключение. Добавление начинается с SSH на порту 22.
- Из активной SSH-карточки «Файлы» открываются по значку папки. У выключенного туннеля действие остаётся в меню.
- Системная кнопка «Назад» в подразделах MQTT возвращает на экран настроек.
