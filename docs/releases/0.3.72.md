## Ничего поверх экрана блокировки

- Пока приложение заперто входом по отпечатку, внешние окна, которые оно открывает само, не появляются поверх экрана блокировки. Например, просмотрщик или окно «Поделиться» после загрузки файла, установщик обновления, внешняя ссылка со страницы устройства. Такое окно ждёт разблокировки. Это касается и окон, которые приложение открывает, пока его нет на экране, если при возврате оно уже было бы заперто.
- Ждёт только последнее такое окно, и после разблокировки оно открывается один раз. Если вы ушли из приложения, не разблокировав его (в том числе с открытым запросом отпечатка), окно отменяется. Действие можно повторить.
- Запрос отпечатка и ввод кода телефона это правило не задевает.
