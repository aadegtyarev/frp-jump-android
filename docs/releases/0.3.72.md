## Ничего поверх экрана блокировки

- Пока приложение заперто входом по отпечатку, внешние окна, которые оно открывает само, не появляются поверх экрана блокировки. Например, просмотрщик или окно «Поделиться» после загрузки файла, установщик обновления, внешняя ссылка со страницы устройства. Такое окно ждёт разблокировки.
- Ждёт только последнее такое окно, и после разблокировки оно открывается один раз. Если вы ушли из приложения, не разблокировав его, окно отменяется. Действие можно повторить.
- Запрос отпечатка и ввод кода телефона это правило не задевает.
