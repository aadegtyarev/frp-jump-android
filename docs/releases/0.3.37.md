# 0.3.37 — общая сетка кнопок терминала

Основные и дополнительные клавиши теперь привязаны к одним колонкам. В обычном портрете кнопки стоят ровно друг над другом; на широком экране дополнительные клавиши сохраняют компактный один ряд с половинным шагом. При крупном шрифте они переносятся блоками по той же сетке.

Значок «…» выровнен с колонкой клавиатуры и последним дополнительным рядом. Его область нажатия не перекрывает соседние клавиши и остаётся внутри доступной ширины, в том числе на узких экранах.

Порядок и действия клавиш, жесты клавиатуры и вставки, защита многострочной вставки и привязка к адресату не изменены. Отдельной строки подсказок не добавлено.
