- Отмена вместо вопроса и для отключения: «Отключить», «Отключить все» и кнопка отключения на «Устройствах» срабатывают сразу, сверху «Отключено: N» с кнопкой «Отменить». Пока плашка видна, терминалы, «Файлы» и MQTT через этот туннель живы — «Отменить» возвращает всё как было; когда плашка уходит, туннель отключается по-настоящему. «Отключить все» из уведомления — сразу, как раньше.
- Закрытие вкладки терминала — без вопроса, с «Отменить», shell завершается, когда плашка уходит.
- Вкладка «Сессии»: у каждой сессии есть ✕, тоже с «Отменить».
