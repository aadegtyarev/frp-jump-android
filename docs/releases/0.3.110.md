## Терминал

- Тап по терминалу по умолчанию оставляет клавиатуру скрытой. Открыть её можно кнопкой ⌨. Прежнее поведение включается в настройках терминала.
- Кнопка Fn в панели дополнительных клавиш открывает F1–F12, а 123 переключает их на цифры. Обе раскладки доступны при скрытой клавиатуре.

## Помощник

- Чат показывает ответы и запросы, требующие вашего решения. Вывод команд можно попросить отдельно.
- При исчерпании шагов помощник пытается дать итог по уже собранным данным.
- Из ответа можно перейти прямо в упомянутую терминальную вкладку.
