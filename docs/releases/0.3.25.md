- MQTT, Wiren Board: копирование по тапу. Тап по названию контрола копирует его в коротком виде (устройство/контрол), долгое нажатие — полный MQTT-топик. Тап по значению, которое только показывается (датчики, тревоги и другие контролы только для чтения), копирует его так, как его опубликовал контроллер; если значения нет или ошибка чтения («—»), приложение скажет, почему не скопировано. У переключателей, слайдеров, полей ввода, списков, цвета и кнопок тап по самому элементу, как и раньше, меняет значение. Карточку топика открывает кнопка «Карточка» в уведомлении о копировании.
- MQTT: «Подключение…» и «Переподключение…» показываются в подзаголовке, без отдельной плашки (при открытом поиске плашка остаётся). Плашки остались там, где нужно действие или причина: вход на брокер, ошибка подключения с «Повторить», закрытие сессии вместе с туннелем.
