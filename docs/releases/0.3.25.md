- MQTT, Wiren Board: копирование по тапу. Тап по названию контрола копирует его в коротком виде (устройство/контрол), долгое нажатие — полный MQTT-топик. У переключателей, слайдеров, полей ввода, списков, цвета и кнопок тап по самому элементу, как и раньше, меняет значение. Карточку топика открывает кнопка «Карточка» в уведомлении о копировании.
