## Исправления

- Если в веб-подключении по HTTPS вы нажали «Доверять», а сохранить доверие к сертификату не удалось, страница по-прежнему не открывается. Теперь об этом сказано честно: «Не удалось сохранить доверие к сертификату (нет места / нет доступа / ошибка записи). Не открыто.», с кнопкой «Попробовать снова». Раньше показывалось, будто вы не доверились. После успешного «Доверять» старая ошибка больше не висит над страницей.
- Ошибка сохранения ключа хоста в терминале, Files и «Использовать вход по ключу» теперь называет только вид сбоя, такими же словами. Пути к файлам и внутренние сообщения в ней не показываются.
