- Терминал не теряет работу при обрыве, если на машине есть tmux (2.4 или новее): каждая вкладка открывается в своей tmux-сессии, после переподключения приложение возвращается в неё — команды продолжали работать, экран как был, сверху «Сессия восстановлена». Закрытие вкладки завершает её tmux-сессию на машине (если связь в этот момент есть).
- Без tmux всё как раньше: после переподключения — новая оболочка. Если tmux на машине не запускается, вкладка сама переходит на обычную оболочку.
- После прокрутки истории вверх первое нажатие сначала выводит tmux из режима прокрутки, затем уходит в оболочку.

Terminal tabs run in tmux when the device has it and re-attach after a dropped connection; plain shell otherwise.
