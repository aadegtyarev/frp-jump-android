- Файлы на устройстве по SSH: просмотр папок, симлинки, скачать на телефон, загрузить с телефона, поделиться, открыть в другом приложении. «Файлы» — в меню ⋮ SSH-подключения и в панели терминала.
- Вкладки сессий в терминале: «+» открывает ещё одну сессию с тем же логином, долгое нажатие на «+» — войти другим пользователем, долгое нажатие на вкладку — закрыть или переподключить.
- «Терминал» на подключении возвращает в уже открытую сессию. Выход из терминала сессии не останавливает — они на вкладке «Терминалы»; закрытие живой сессии спрашивает подтверждение, крестика в панели больше нет.
- Порт 80 всегда HTTP, 443 всегда HTTPS; если устройство отвечает по HTTP вместо HTTPS, приложение так и скажет и предложит открыть по HTTP.
- Пресет порта 80 теперь «HTTP · 80» и не подставляет имя «homeui».
