## Помощник

- Помощник может отправить временный файл через открытый сохранённый веб-туннель. В его инструментах должны быть включены «HTTP POST» и «Временные файлы».
- В карточке подтверждения показаны назначение, путь, имя и размер файла. Разрешения на отправку файлов и текстовый HTTP POST выдаются отдельно.
- После отправки модель получает HTTP-статус. При потере ответа приложение сообщает, что результат неизвестен.
