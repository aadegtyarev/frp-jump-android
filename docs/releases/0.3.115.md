## Помощник

- Помощник может читать ответы HTTP GET через открытый сохранённый веб-туннель. Для этого включите «Чтение веб-туннеля» в инструментах.
- Помощник возвращает статус HTTP и текст ответа в пределах настроенного лимита. HTTPS использует системную проверку или сертификат, которому вы уже доверили в приложении для этого подключения.
