- MQTT, плагин Wiren Board: третья вкладка «Устройства WB» появляется сама, когда на брокере есть устройства Wiren Board. Устройства с названиями на языке телефона и «!» при ошибке; внутри — контролы по порядку, значения с единицами (°C, A, kWh…), названия значений из enum. Управление по типу: реле — переключатель, кнопка, ползунок (диммер), цвет, ввод значения; только для чтения — без управления. Запись идёт в …/on, ответ виден на самом контроле: отправляется → подтверждено устройством, или «Нет ответа от устройства» / «Отказано: …». Тап по названию контрола — обычная карточка топика. Выключается в «Плагинах».
- Терминал: внизу один ряд самых нужных кнопок — ^C, «Вставить», стрелки, ⌫, ⏎ и ⌨. Кнопка ⌨ открывает клавиатуру, и вместе с ней появляются ещё два ряда: Esc, Tab, Ctrl, Alt, ^D ^Z ^R ^L, Home End PgUp PgDn, | ~ / -. Стрелки и ⌫ повторяются, пока их держат.
- Вставка: перенос в конце отрезается, одна строка сама не выполнится; если вставляется несколько строк там, где они выполнились бы сразу, приложение спрашивает: «Вы вставляете N строк» — «Вставить» или «Убрать переносы».
