## Ассистент знает причину ошибки

- Сведения о профилях, которые получает ассистент, теперь называют причину ошибки, а не одну общую фразу. Например: сервер недоступен, сервер ответил ошибкой, туннель не появился в списке вовремя, нет свободного локального порта, нужно обновить приложение или сервер. Так ассистент точнее подсказывает, что делать.
- Ассистенту передаётся только вид ошибки. Текст ответа сервера, адрес, сообщения системы и данные входа ему не передаются.
- Тексты ошибок в приложении не изменились.
- Чаты, сохранённые раньше, открываются как прежде.

## Внутренние изменения

- Ошибки туннелей и списка устройств хранятся как типы, а текст для экрана собирается при показе. Поэтому после смены языка приложения уже показанные ошибки отображаются на новом языке.
