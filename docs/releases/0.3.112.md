## Помощник

- Помощник может читать последние значения тем, уже полученные в открытой MQTT-сессии. Включите «Чтение сообщений MQTT» в инструментах помощника.
- Можно указать тему или маску. Чтение работает по уже полученным сообщениям и не создаёт подписок.
