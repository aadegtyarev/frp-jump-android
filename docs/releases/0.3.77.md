## Число туннелей на значке

- Уведомление о туннелях теперь сообщает лаунчеру, сколько туннелей открыто. Лаунчеры, которые показывают числа (например, Samsung), выводят его на значке приложения; остальные показывают точку, а уведомление видно в меню по долгому нажатию.
- Считаются туннели, а не соединения: несколько соединений на один порт устройства — один туннель. Число совпадает с заголовком уведомления.
- Значок приложения не меняется. Настройки значков в системе и для приложения по-прежнему действуют.
