# 0.3.45

Невыбранная SSH-вкладка больше не может автоматически заменить буфер обмена командой OSC 52. Переключение вкладки сразу отзывает это право у прежней; запоздалые callbacks удалённого или заменённого терминала не получают прав нового.

Выбранная вкладка и ручное копирование работают по-прежнему. Уход с экрана терминала и перевод приложения в фон не меняют последнюю выбранную SSH-вкладку. Новых запросов разрешения, настроек или ограничений для неё нет; прежний предел длины копирования сохранён.
