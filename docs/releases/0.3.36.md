# 0.3.36 — читаемый значок WB

Wiren Board теперь обозначается контрастной монограммой **WB** вместо мелких деталей DIN-модуля. Значок используется в списках устройств, заголовках подключений и выборе оформления.

Существующий значок ПК (монитор с системным блоком) и название «Компьютер» сохранены без изменений. Отдельный вариант мини-ПК в этот релиз не входит.

Серверные значения значков, сохранённый выбор и приоритет ручного выбора над автоопределением не изменены. Изменений терминала, MQTT-записи и правил readonly в этом выпуске нет.
