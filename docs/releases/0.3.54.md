# 0.3.54

## Исправления помощника

- Публичные веб-запросы используют браузерные заголовки и язык системы.
  Поиск по-прежнему зависит от доступности сервиса и его ограничений.
- Ошибки инструментов показываются прямо в чате: какой инструмент не сработал,
  известная причина и HTTP-статус, а для поиска — сгенерированный запрос.
  Объяснение остаётся доступным и после отказа следующего запроса модели.
- Поиск по сведениям о профилях поддерживает части имени устройства, подписи
  и названия подключения. Можно получить несколько подходящих вариантов,
  различить одинаковые имена в разных профилях и продолжить большую выдачу
  без обрезания записей посередине.
- Полученные сведения о профилях можно раскрыть и скопировать в чате.
  Если следующий запрос модели не удался, они показываются автоматически.
  Недоступные и устаревшие источники отмечаются отдельно.

Эта версия не добавляет SSH-сессии или фоновые команды и не меняет ограничения
чтения страниц и анализа изображений.
