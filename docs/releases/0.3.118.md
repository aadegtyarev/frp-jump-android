## Помощник

- Включите «Временные файлы» в инструментах помощника. Он сможет создавать текстовые файлы, смотреть список и просматривать часть содержимого по запросу.
- Файлы остаются доступны при выходе из чата. Они удаляются при очистке чата, смене провайдера, выключении помощника или перезапуске приложения.
