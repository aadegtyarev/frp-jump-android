# 0.3.44

Ошибка сохранения или удаления MQTT-логина на телефоне больше не оставляет принятое брокером подключение в состоянии «Подключение». Подписки и получение данных продолжают работать; отдельное предупреждение честно сообщает о состоянии сохранённых данных.

Кнопка «Повторить» повторяет только запись на телефоне — без переподключения и повторной подписки. Старое предупреждение не может сохранить другие, позже введённые данные. Ошибка чтения хранилища больше не считается пустым файлом и не приводит к незаметной перезаписи других сохранённых логинов.
