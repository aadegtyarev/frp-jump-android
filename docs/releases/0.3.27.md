- Терминал: в настройках появился раздел «Терминал» с переключателем «Прямой ввод». По умолчанию он выключен, в том числе после обновления: приложение больше не отправляет набираемое слово раньше, чем его подтвердит клавиатура. Клавиатура может использовать свою буферизацию и подсказки.
- Если нужен прежний посимвольный ввод для команд и сочетаний Ctrl/Alt, включите «Прямой ввод». Настройка сохраняется для всех терминалов. Аппаратные клавиши работают в обоих режимах.

Terminal: direct character input is now an opt-in setting under Settings → Terminal, disabled by default on new and existing installations. Normal mode allows keyboard composition and suggestions; enable Direct input to restore immediate character forwarding. Hardware keys work in either mode.
