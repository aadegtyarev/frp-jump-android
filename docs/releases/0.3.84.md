## Терминал: сворачивание снова плавное

- Когда клавиатура, панель клавиш или текстовое поле закрываются, терминал снова растёт вместе с анимацией, как до 0.3.83: без паузы и без пустой полосы сверху.
- Разворачивание осталось как в 0.3.83: терминал перестраивается один раз, когда клавиатура, панель или поле встали на место, а нижняя строка с курсором всё это время прижата.
- Серверу по-прежнему уходит только установившийся размер: tmux не перерисовывается на каждом кадре.

Закрытие (эмулятор, портрет, шрифт 100%):

| | До 0.3.83 | 0.3.83 | 0.3.84 |
| --- | --- | --- | --- |
| Терминал при закрытии клавиатуры | растёт вместе с анимацией | ждёт ~0,3 с с пустой полосой | растёт вместе с анимацией |
| Размеров, отправленных на сервер | 6 | 1 | 1 |

## Проверка

- Эмулятор API 35, проход e2e на 264bc96 (main), установленные APK сверены по sha256. Конфигурации: портрет 100% RU и ландшафт 200% EN. Общий набор — 49 классов, по 297 тестов; тесты экрана чата — по 47. Всё зелёное, кроме одного нестабильного теста: AssistantProviderScreenTest (выбор модели у провайдера) упал один раз в портрете и прошёл при повторе; задача #249. Пропущены только тесты, которым нужен PIN экрана на устройстве.
