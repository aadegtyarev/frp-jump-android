## Вход по отпечатку: когда приложение запирается

- Новая настройка «Запирать через» в разделе «Безопасность», рядом с «Вход по отпечатку». Варианты: «Сразу», 30 с (по умолчанию, как раньше), 1, 5 и 15 мин. Строка видна, только пока вход по отпечатку включён.
- Приложение спрашивает отпечаток или код телефона при запуске с нуля и когда оно было не на экране дольше выбранного времени. Пока работают туннели, приложение не закрывается полностью, поэтому возврат в него — не запуск с нуля: решает только выбранное время.
- После окна, которое открыло само приложение (выбор фото или файла, «Поделиться», установщик, системные настройки, браузер или SSH-клиент из карточки соединения), приложение спрашивает не раньше чем через 30 с, даже при варианте «Сразу». Так вставка картинок и выбор файлов не требуют отпечатка каждый раз.
- Если запрос отпечатка пропал без ответа (например, Android пересоздал экран), приложение не ждёт его бесконечно: оно остаётся запертым и спрашивает снова.
