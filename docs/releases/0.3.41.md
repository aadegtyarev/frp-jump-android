# 0.3.41

Исправлено владение передачами при уходе с экрана Files и возврате в сохранённую сессию. Отмена сразу захватывает старые задачи; отложенное ожидание очистки больше не отменяет новые передачи. Поздние метаданные upload и progress старого посещения не восстанавливают очищенные строки.
