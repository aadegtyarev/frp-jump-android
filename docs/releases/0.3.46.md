# 0.3.46

Устранено переполнение стека при обходе MQTT-топиков с большим числом уровней: в поиске, сопоставлении фильтров, сводках подписок и сборе значений для плагинов.

Обход теперь использует явные итераторы вместо рекурсивных вызовов. Нового ограничения глубины нет; правила фильтров, относительные пути, порядок результатов, история значений и прежние лимиты не меняются. Настройки числовых лимитов и поведения при переполнении будут отдельным слайсом.
