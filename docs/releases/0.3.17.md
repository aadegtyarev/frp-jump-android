- Файлы: просмотр текста переведён на Sora Editor с грамматиками TextMate (как в VS Code). Подсвечиваются Markdown (с блоками кода), логи, JSON (и `.conf` Wiren Board с JSON внутри), YAML, ini/properties/systemd/`.env`/TOML, shell, JavaScript, Python, Go, C, Lua, Dockerfile, SQL, XML/SVG, HTML, CSS. Поиск считает все совпадения; длинные строки переносятся целиком; строки длиннее 16 тыс. символов не переносятся (в меню сказано почему). Большой лог (2 МБ) открывается сразу, цвета появляются через несколько секунд.
- Настройки: «Компоненты и лицензии» — все использованные библиотеки и программы с версиями, полными текстами лицензий и ссылками на исходники; в карточке frpc — список встроенных в него Go-модулей.
