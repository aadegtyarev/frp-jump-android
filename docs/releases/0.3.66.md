## Вставка картинки в терминал

- В меню ⋮ терминала появился пункт «Вставить изображение». Выбранное фото отправляется на устройство по уже открытому SSH-соединению вкладки, и путь к нему вставляется в терминал как обычная вставка, без Enter. Claude Code и похожие программы принимают такой путь как вложение.
- Если в буфере телефона лежит картинка, а не текст, кнопка вставки предлагает вставить её.
- Перед отправкой картинка уменьшается до 2000 px по длинной стороне и пересохраняется без метаданных: геометки, данные камеры и цветовые профили на устройство не попадают.
- Файлы сохраняются в `~/.cache/frp-jump/images`, доступ к ним есть только у владельца. При следующих вставках файлы старше 60 минут удаляются.
- Пока идёт отправка, видна полоса с процентами и кнопкой «Отмена». При ошибке путь не вставляется, а приложение показывает причину. На устройстве должна быть включена передача файлов (SFTP).
- Внутри приложения подготовлено ядро подтверждений для ассистента. Видимых изменений пока нет.
