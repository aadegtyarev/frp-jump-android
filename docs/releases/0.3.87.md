## Помощник читает открытые вкладки терминала

- **Новый переключатель «Вкладки терминала»** в Инструментах, по умолчанию выключен. Включённый, он даёт помощнику два инструмента: список открытых вкладок (профиль, устройство, подключение, пользователь, номер вкладки, состояние, а для вкладок с tmux — программа на экране) и чтение одной вкладки: экран и до 1000 строк истории.
- **Без нового входа и без ввода.** Вкладку с tmux помощник читает через её же подключение командой `tmux capture-pane`, остальные — из буфера терминала в приложении. Во вкладку ничего не вводится. Скрытые вкладки помощник не видит. Если вкладка закрыта или переподключается, он получает отказ и запрашивает список заново.
- **Содержимое терминала уходит провайдеру модели** и может содержать секреты: об этом предупреждает подпись переключателя. Для модели прочитанное — недоверенные данные, а не указания.
- В чате вызовы подписаны: «Список вкладок» и «Чтение вкладки · профиль · user@device №1».

## Помощник сам добывает ответ

- **Меньше вопросов «сказать — и я проверю».** Помощник сам собирает данные всеми доступными инструментами и доводит проверку до ответа. Безобидные шаги вроде обновления списков пакетов, чтения журналов и настроек, чтения changelog из репозитория (или из пакета, скачанного во временную папку и затем удалённого) он делает без спроса.
- **Изменения — только по просьбе.** Установку, обновление и удаление программ, правку настроек, перезапуск служб, перезагрузку и удаление данных помощник делает, только если вы об этом попросили; иначе перечисляет их в конце ответа. Подтверждения перед изменяющими командами, когда они включены, работают как раньше.

## Чат: развёрнутый вызов без служебных строк

- **Раскрытый вызов показывает результат, а не дамп.** Больше нет служебного имени инструмента, аргументов в JSON и слова `SUCCESS`. У команды SSH первой строкой — полная команда (`$ …`), скрытые символы в ней видны. Если вызов не удался, это сказано словом: «Не удалось», «Время вышло», «Инструмент недоступен», «Отклонено».
