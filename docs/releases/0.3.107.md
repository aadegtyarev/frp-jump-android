## Обновлённый экран «Сессии»

- Ищите сессии по названию, пользователю или устройству. Нажатие возвращает в существующую сессию.
- Крестик закрывает одну сессию. Для закрытия нескольких удерживайте строку и отметьте нужные. «Отменить» возвращает сессии, а туннель остаётся включённым.
- Кнопка «Терминал» у SSH-туннеля открывает единственную вкладку или предлагает выбрать из нескольких. Если вкладок ещё нет, она запускает новую сессию.
