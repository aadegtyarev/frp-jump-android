# 0.3.40 — редактор во всех SSH-вкладках

Исправлено долгое нажатие на клавиатуру при нескольких SSH-сессиях: редактор открывается в выбранной вкладке, а не работает только в одной из них. Обработчик действия обновляется при смене вкладки.

Сохранены отдельные черновики и проверки принадлежности callback выбранной сессии. Короткое нажатие по-прежнему переключает IME; вставка, её подтверждения и дополнительный Enter от долгого Insert не менялись.
