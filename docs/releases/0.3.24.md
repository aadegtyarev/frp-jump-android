- Устройства: подпись и значок. В карточке устройства, в меню ⋮, есть «Подпись…» и «Значок…»: можно задать понятную подпись до 64 символов (например, «Щиток, гараж») и выбрать значок. Подпись видна в списке устройств, на карточке и в «Подключениях», по ней работает поиск. Нужен сервер frp-jump 0.3.19 или новее; со старым сервером пунктов меню нет.
- MQTT: в заголовке полное имя устройства, строкой ниже порт и состояние подключения. Вкладки в одну строку, вкладка плагина называется «WB». Строка пути больше не похожа на поле ввода; ввести топик можно через ⋮ → «Перейти к топику». У $SYS в строке видно, почему он пуст: не подписаны, сообщений нет или нет доступа.
- MQTT, Wiren Board: одна стрелка «назад» внутри устройства. При ошибке чтения вместо значения «—», переключатель и тревога приглушены. Числа без лишних нулей: 76.50171 вместо 76.501710.
