## Уточнения экрана «Сессии»

- Поиск выровнен по значку. Между поиском и списком появился отступ.
- Все SSH-сессии оформлены одинаково: видны пользователь, устройство, порт и профиль. Сессии помощника отмечены значком.
- После окна отмены приложение ждёт подтверждения закрытия сессии помощника. При сбое карточка показывает причину и путь к туннелям устройства.
