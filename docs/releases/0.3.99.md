## Карточка туннеля аккуратнее

- Кнопка главного действия (терминал, глобус, MQTT, копировать) теперь в ободке без заливки — как ⏻. Все круглые кнопки чуть крупнее (36 dp).
- Строка состояния больше не оставляет висящую точку: если адрес не помещается рядом с «Через сервер ›», он переходит на свою строку.
- Строка «SSH … ↓ … ↑ … ›» занимает всю ширину карточки и не рвётся, стрелка › в конце.
- Под кнопками свайпа есть подписи: «Спросить помощника», «В избранное» / «Убрать из избранного». Звёздочка в заголовке «Избранные» — приглушённая, как на карточках.

## frp-jump представляется удалённой машине

- При входе по SSH приложение передаёт переменные LC_TERMINAL=frp-jump и LC_TERMINAL_VERSION=<версия> (так же делает iTerm2); в сессиях tmux приложения те же переменные есть в окружении. Если сервер их не принимает, вход идёт как обычно. Никаких данных о вас — только имя и версия приложения.

## Проверки

- На main c3f022e: все юнит-тесты (приложение 2907, ядро 47, OpenAI 46) и lint без ошибок.
- Эмулятор: карточка туннеля (в светлой и тёмной теме), избранное и свайпы, шапка — 23 теста в портрете по-русски и в альбоме 200 % по-английски. Снимки просмотрены.
- LC_TERMINAL проверен на тестовом SSH-сервере; на настоящем sshd и tmux 3.2+ — при первом входе с телефона.
