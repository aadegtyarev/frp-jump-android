# 0.3.52

## Сведения об устройствах и подключениях в чате

Помощник может получить известные приложению сведения об устройствах, сохранённых подключениях и туннелях во всех профилях — включая устройства без сохранённых подключений. Одинаковые имена устройств различаются по профилю. Источник данных общий с экранами «Устройства» и «Подключения».

Новый переключатель в «Инструментах» выключен по умолчанию. Открытие чата, включение или сохранение настройки сами по себе не отправляют сведения. Изменения переключателей действуют со следующей отправки и не очищают диалог.

При вызове инструмент один раз выполняет обычное обновление списков устройств всех профилей, затем возвращает известное приложению состояние. После ошибки обновления сведения могут быть устаревшими или недоступными; это отражается в результате.

При использовании инструмента частные сведения о профилях, устройствах и подключениях передаются настроенной модели; сохраняется обычная оплата токенов. Сохранённые учётные данные (пароли, токены и ключи) и исходные технические сообщения об ошибках в результат не включаются.

Инструмент информационный: не подключает и не отключает туннели, не выполняет команды SSH или HTTP-запросы к устройствам и не даёт доступа к файлам. Остановка запроса отзывает дальнейшие запуски; уже допущенная сетевая работа может завершаться, и новый запрос ждёт её фактического выхода.
