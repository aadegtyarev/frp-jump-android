Первая подписанная версия. Ставится вручную один раз, поверх отладочной не встанет: удалите её и подключите телефон заново по QR. Следующие версии придут через «Обновить» в настройках.

- Профили: несколько серверов и учёток сразу, у каждого цвет.
- Без сети показываются последние известные списки.
- Подключения с именами к любому порту, вкладка «Подключения», «Отключить» прямо на строке.
- Сначала пробует напрямую (P2P), если не вышло, работает через сервер и предлагает повторить.
- Туннели поднимаются сами после перезагрузки телефона.
- Подключение телефона по QR-коду.
- Русский и английский, светлая и тёмная темы, вход по отпечатку, «Скрывать в недавних».
- Сохранённые команды и спецклавиши в терминале.
- Веб-страницы и терминал на весь экран, тонкие заголовок страницы и нижняя панель.
- Своя иконка.
- Если порт туннеля занят другим приложением, туннель переезжает на свободный.
- Обновления внутри приложения с проверкой подписи.

---

First signed release. Install it by hand once: it does not go over the debug build, so uninstall that and enroll the phone again by QR. Later versions come through Settings › Update.
