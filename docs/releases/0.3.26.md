- MQTT: в настройках приложения появился раздел «Плагины». Общие переключатели Wiren Board и топиков статуса и команд действуют для всех MQTT-подключений без своих настроек.
- У каждого плагина есть экран с общим переключателем и списком подключений-исключений. «Как в настройках» возвращает подключение к общему значению.
- В окне «Плагины» отдельного подключения теперь видно, откуда взято значение: из настроек приложения или только для этого подключения. Тап по названию открывает экран плагина; назад возвращает в окно подключения.
- Готовые и собственные правила топиков статуса и команд пока остаются в окне подключения; их перенос на экран плагина будет отдельным обновлением.

MQTT plugins now have app-wide switches in Settings, individual plugin screens and a list of connection-specific overrides. Each connection's Plugins sheet shows whether it follows Settings and offers a reset. Status/command presets and custom rules remain in the connection sheet for now.
