- Файлы: просмотр текста в приложении. Текстовые файлы до 2 МБ открываются внутри, с подсветкой: Markdown, логи (ERROR красным, WARN жёлтым), JSON (и `.conf` Wiren Board с JSON внутри), YAML, ini/conf/systemd, shell, JavaScript (wb-rules). В «⋮» — перенос строк, номера строк, размер текста, «Копировать всё», «Поделиться», «Открыть с помощью»; поиск по тексту. Бинарные и большие файлы, как раньше, открываются в другом приложении. Копия для просмотра удаляется при закрытии.
- Устройства: свайп влево по строке устройства с открытыми туннелями — красная кнопка питания, отключает туннели только этого устройства («Отключено: N · Отменить»). Такая же кнопка — в заголовке карточки устройства, пока у него есть туннели.
