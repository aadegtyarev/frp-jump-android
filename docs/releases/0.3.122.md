## Помощник

- На каждом ходе с инструментами модель получает число оставшихся шагов и максимум вызовов за шаг.
- После обычного лимита помощник может выполнить ещё два шага с инструментами, чтобы закончить начатое.
- Список инструментов остаётся в запросах к модели до итогового ответа. Когда запас шагов исчерпан, помощник даёт модели последнюю возможность ответить по собранным данным.
