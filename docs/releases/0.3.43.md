# 0.3.43

Если подключение сохранено, но его не удалось запустить, приложение сообщает об этом без совета удалить телефон на сервере. Кнопка «Повторить запуск» использует те же сохранённые данные — новый QR-код и повторное добавление не нужны.

Незапущенное подключение остаётся в списке и после перезапуска приложения. Оно не мешает уже работающим подключениям; его можно запустить вручную или удалить. Повтор из старого экрана не переключает подключение с изменившимися данными. Ошибка сохранения до записи данных по-прежнему сообщается отдельно.
