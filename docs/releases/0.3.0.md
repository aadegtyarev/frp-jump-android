- MQTT-обозреватель (первый этап): новый вид подключения MQTT, пресет 1883. Кнопка «MQTT» поднимает туннель и открывает дерево топиков брокера; у TCP-подключения в «⋮» есть «Открыть как MQTT». Дерево листается как папки: строка пути, живые значения открытой ветки, отметка retained, поиск по пути, ввод пути вручную, $SYS. MQTT 5 с переходом на 3.1.1, вход по логину, если брокер просит. Сессия живёт, пока не закроете её, «MQTT» возвращает в неё.
