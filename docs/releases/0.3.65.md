## Инструкции ассистента из одного источника

- Инструкции для модели ассистента теперь хранятся в одном месте: системный промпт в `skill.md` и отдельный короткий промпт для сводки разговора в `summary.md`.
- Системный промпт одинаков в каждом запросе разговора, поэтому провайдер может кэшировать его начало.
- Новые указания модели:
  - по SSH сначала смотреть, потом менять;
  - перед изменяющей командой объяснять, что она сделает;
  - не просить пароли и ключи, а при ошибке входа отправлять в SSH-экраны приложения;
  - читать найденные страницы, а не только фрагменты из поиска, и называть источники.
- Если файл инструкций повреждён, отправка завершается обычной ошибкой настройки, без запасного текста.
