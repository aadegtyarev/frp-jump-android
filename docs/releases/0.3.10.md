- MQTT, «Записать…»: переключатель Текст / JSON. JSON проверяется по ходу ввода («Не JSON: строка 1, столбец 5»), «Отформатировать» расставляет отступы.
- Под полем «Значение» — «Отправляли раньше»: последние 10 значений, отправленных в этот топик, одним нажатием.
- Retain, QoS и формат запоминаются для каждого топика и при следующей записи стоят как в прошлый раз. Запоминается только то, что ушло с телефона; удаляется вместе с подключением.
- Глубина вложенности JSON (в окне записи и в карточке топика) теперь проверяется по разобранному значению, а не по тексту.
