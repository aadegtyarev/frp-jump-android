# 0.3.50

## Читаемый чат с помощником

Сообщения в чате оформлены как единый текстовый диалог: подписи «Вы» и «Помощник» различают роли, текст пользователя выделен акцентным цветом.

Ответы поддерживают базовое форматирование: жирный и курсивный текст, списки, встроенный код и блоки кода. Текст остаётся доступным для выделения; оформление не меняет историю диалога и сообщения, отправляемые провайдеру. Если разбор форматирования не удался, показывается исходный текст ответа.

Ссылки, изображения и HTML показываются как неактивный текст: ничего не открывается и не загружается. Веб-поиск, чтение страниц и просмотр изображений в этот релиз не входят.
