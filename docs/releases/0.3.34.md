- Терминал: уже считанный writer-ом блок и данные, оставшиеся в очереди при переподключении, больше не направляются в новый SSH-поток. Воспроизведён случай, когда writer ждал выхода из tmux copy mode, а поток успевал смениться; теперь блок привязан к исходному потоку и поколению соединения.
