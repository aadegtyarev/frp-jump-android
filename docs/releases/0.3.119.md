## Помощник

- Когда лимит шагов исчерпан, помощник просит модель дать обычный текстовый ответ по уже полученным результатам и указать, каких данных не хватило.
- Служебная разметка вызова DeepSeek, вернувшаяся в тексте ответа, отклоняется. Чат предложит повторить запрос, если модель не дала полного ответа.
